# by-yourself-social

**The only social network with a population of one.**

Social media was designed to keep you scrolling, comparing, performing, and never quite enough.  
by-yourself-social does the opposite.

Here there are no other people.  
No likes. No followers. No algorithms. No notifications. No public metrics.  
Just you, your thoughts, and the quiet.

### What we inverted

| Social Media | by-yourself-social |
|--------------|--------------------|
| Infinite feed of everyone | Finite journal of only yourself |
| Likes & validation | Zero public signals. Private depth only |
| Algorithmic outrage | No algorithm. Chronological self only |
| FOMO | JOMO. Everything is delayed or private |
| Notifications | Silence by default |
| Performative posting | Whisper to the void (or future-you) |
| Data harvesting | 100% local. Your data never leaves the browser |
| Addiction loops | Hard daily limits + forced log-off |
| Comparison | You are the only user. Perfect. |

### How to use
1. Write a whisper (optional mood).
2. Optionally seal it as a time capsule for future-you.
3. Reflect.
4. Leave.
5. Come back only when you actually want to.

This is not a product to grow. It is a tool to shrink the noise.

Built as a pure client-side experience. No accounts. No servers. No tracking.

**Live demo (once Pages enabled):** https://agentmindcloud.github.io/by-yourself-social/

### Enabling GitHub Pages
1. Go to the repository Settings → Pages
2. Under "Build and deployment" → Source: Deploy from a branch
3. Branch: `main` / folder: `/ (root)`
4. Save. The site will be live in ~1 minute at the URL above.

### Features
- **The Void**: Your personal timeline of whispers (self-posts only)
- **Whisper to Yourself**: Post with mood + optional time capsule
- **Hard daily limit**: 3 whispers per day
- **Session timer**: 10 minutes max, then forced "Leave & Be Present"
- **Solitude stats**: Private counters for quiet days, whispers, depth
- **Time Capsules**: Schedule posts to reveal only to future-you
- **Export / Import**: Your data stays yours
- **Friction by design**: Random reflection prompt before you can post
